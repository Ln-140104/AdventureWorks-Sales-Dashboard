# AdventureWorks-Sales-Dashboard
Project Overview

An interactive Power BI dashboard analyzing the 2020 sales performance of AdventureWorks. This project transforms raw transaction data into actionable financial insights, tracking revenue, profit margins, and regional trends.

Tools & Techniques

Data Engineering: Power Query (ETL, removing duplicates, defining data types).
Data Modeling: Star Schema design establishing strict 1-to-Many relationships.
Analytics: Advanced DAX (SUMX, RELATED) for dynamic metric calculation.
Visualization: Power BI Desktop (Interactive slicers, KPI cards, matrix formatting).

Key Insights

Financial Health: Driven $31.84M in total revenue with a highly efficient 41.44% profit margin.
Top Markets: Australia and the United States led global sales, significantly outpacing other territories.
Seasonality: Exhibited strong seasonal revenue peaks throughout the Q4 holiday season
